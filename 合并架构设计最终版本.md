### 1.3 主循环代码 —— Application::run()

```cpp
// Application.cpp — 主循环实现
void Application::run() {
    sf::Clock clock;
    while (m_window.isOpen()) {
        // 1. 计算帧时间
        m_deltaTime = clock.restart().asSeconds();
        if (m_deltaTime > 0.05f) m_deltaTime = 0.05f; // 防止卡顿时 dt 过大

        // 2. 处理窗口事件 → 分发给当前场景
        processEvents();

        // 3. 更新当前场景 + 帧末执行延迟切换
        update();

        // 4. 渲染
        render();
    }
}

void Application::processEvents() {
    while (const std::optional<sf::Event> event = m_window.pollEvent()) {
        if (event->is<sf::Event::Closed>()) {
            m_window.close();
        }
        else {
            // 事件分发给场景栈顶
            m_sceneManager.handleEvent(*event);
        }
    }
}

void Application::update() {
    if (!m_sceneManager.isEmpty()) {
        m_sceneManager.update(m_deltaTime);
        // update 内部：调用栈顶场景的 update() → applyPendingChanges()
    }
}

void Application::render() {
    m_window.clear(sf::Color(10, 5, 20));
    if (!m_sceneManager.isEmpty()) {
        m_sceneManager.render(m_window);
    }
    m_window.display();
}
```

### 2.2 核心枚举 —— JudgeResult

```cpp
// common/Types.h — 全局共用枚举

enum class JudgeResult {
    Perfect,  // 完美判定 — 音符距离判定线 < 20px
    Great,    // 优秀判定 — 音符距离判定线 < 50px
    Good,     // 良好判定 — 音符距离判定线 < 100px
    Miss,     // 错过判定 — 音符超出判定窗口或未击打
```

### 2.6 ★ 融合新增 —— NoteRuntime

```cpp
// common/Types.h — ★ 融合新设计
// 将第一位队友的 NoteData（静态数据）和运行时状态合并为一个结构

struct NoteRuntime {
    // —— 来自 NoteData（谱面数据，只读） ——
    int   track;       // 轨道 (0-3)
    float targetTime;  // 理论击打时间（秒）
    int   type;        // 0=普通, 1=长按

    // —— 运行时状态（每帧由 GameplayScene 更新） ——
    float y;           // 当前屏幕 Y 坐标
    float noteSpeed;   // 下落速度（像素/秒）
    bool  processed;   // 是否已判定（onHit/onMiss 后设为 true）
    bool  active;      // 是否在活跃中（未移出屏幕）
};
```

**为什么要新增：**
- 第一位队友的做法：`NoteData` + `sf::CircleShape`（位置信息混在渲染对象里）
- 第二位队友的做法：`NoteRuntime` 结构隔离数据和渲染，`sf::CircleShape` 只负责绘制
- 融合方案：采用 `NoteRuntime` 管理状态，`sf::CircleShape` 仅做视觉表现

### 2.7 模块间的数据传递流程

```
① 谱面加载阶段
   song.json ──► BeatmapParser::loadFromFile()
                   ├── 输出 m_notes: vector<NoteData>
                   └── 输出 m_songInfo: SongInfo

② 音频加载阶段
   SongInfo.musicFile ──► MusicPlayer::load(音频文件)

③ 运行时（每帧）
   MusicPlayer::getCurrentTime() ──► GameplayScene::spawnNotes()
                                       │
                                       ├── 创建 NoteRuntime{ track, targetTime, y, ... }
                                       └── 推入 m_noteRuntimes

   sf::Keyboard::Key::D/F/J/K ──► GameplayScene::checkJudgment(track)
                                       │
                                       ├── 从 m_noteRuntimes 找最近音符
                                       ├── 计算像素距离判定等级
                                       └── 调用 onNoteJudged(result, track)

   onNoteJudged() ──► 更新 m_score / m_combo
                    ├── 创建 sf::CircleShape 渲染用
                    ├── 更新 HUD 文字
                    ├── m_hitFX.emit() 爆发粒子
                    └── 标记 NoteRuntime.processed = true

④ 结束阶段
   所有音符判定完毕 ──► endGame()
                         └── requestReplace(ResultScene)
                              └── ResultScene 读取结算数据
```

## 三、UI/流程层（基于第二位队友的框架）

### 3.1 IScene —— 场景抽象基类

**定位：** 所有游戏画面的统一接口。一个场景 = 一整个画面状态（标题、菜单、曲包、演奏、结算）。

```cpp
// scenes/IScene.h
#pragma once
#include <SFML/Graphics.hpp>
#include <memory>

class SceneManager;

class IScene {
public:
    virtual ~IScene() = default;

    // ── 生命周期钩子 ──
    virtual void onEnter() {}   // 场景被激活时调用一次
    virtual void onExit() {}    // 场景被停用前调用一次

    // ── 核心循环接口 ──
    virtual void handleEvent(const sf::Event& event) {}
    virtual void update(float dt) = 0;
    virtual void render(sf::RenderTarget& target) = 0;

    // ── 延迟场景切换（防止 delete this 崩溃） ──
    void requestPush(std::unique_ptr<IScene> scene);
    void requestPop();
    void requestReplace(std::unique_ptr<IScene> scene);

    void setSceneManager(SceneManager* manager) { m_sceneManager = manager; }
    SceneManager* getSceneManager() const { return m_sceneManager; }

protected:
    SceneManager* m_sceneManager = nullptr;
};
```

**设计要点：**
- `update()` 和 `render()` 为纯虚函数，强迫派生类实现
- `requestPush/Pop/Replace` 延迟到帧末执行，避免在 update 中 delete 自身
- `onEnter/onExit` 提供默认空实现，派生类按需覆写

### 3.2 SceneManager —— 场景栈管理器

```cpp
// SceneManager.h
#pragma once
#include <vector>
#include <memory>
#include "scenes/IScene.h"

class SceneManager {
public:
    void pushScene(std::unique_ptr<IScene> scene);
    void popScene();
    void replaceScene(std::unique_ptr<IScene> scene);

    void handleEvent(const sf::Event& event);
    void update(float dt);
    void render(sf::RenderTarget& target);

    bool isEmpty() const { return m_scenes.empty(); }

private:
    void applyPendingChanges();

    enum class Action { None, Push, Pop, Replace };
    struct PendingChange {
        Action action = Action::None;
        std::unique_ptr<IScene> scene;
    };

    std::vector<std::unique_ptr<IScene>> m_scenes;
    PendingChange m_pending;
};
```

**延迟切换机制：**
```
场景 A::update() 调用 requestReplace(B) → 写入 m_pending，不立即执行
控制权回到 SceneManager::update()
  → applyPendingChanges(): A.onExit() → delete A → B.onEnter()
  → 安全，因为 A.update() 已返回
```

```cpp
void GameplayScene::update(float dt) {
    if (!m_isPlaying || m_songFinished) return;
    m_pulseTime += dt;
    m_glowIntensity = 0.5f + 0.3f * std::sin(m_pulseTime * 2.0f);

    float currentTime = 0.f;
    if (m_musicPlayer.isLoaded() && m_musicPlayer.isPlaying())
        currentTime = m_musicPlayer.getCurrentTime();

    spawnNotes(currentTime);

    for (auto& nr : m_noteRuntimes) {
        if (nr.active && !nr.processed)
            nr.y += m_noteSpeedPixels * dt;
    }

    for (size_t i = 0; i < m_activeShapes.size() && i < m_noteRuntimes.size(); ++i) {
        if (m_noteRuntimes[i].active)
            m_activeShapes[i].setPosition(
                getTrackCenterX(m_noteRuntimes[i].track), m_noteRuntimes[i].y);
    }

    autoMissCheck();
    m_hitFX.update(dt);
    if (m_judgmentDisplayTimer > 0) m_judgmentDisplayTimer -= dt;

    if (m_noteIndex >= (int)m_noteData.size() && allNotesProcessed())
        endGame();
}

void GameplayScene::spawnNotes(float currentTime) {
    while (m_noteIndex < (int)m_noteData.size() &&
           m_noteData[m_noteIndex].time <= currentTime + SPAWN_LOOKAHEAD) {
        if (m_noteData[m_noteIndex].time >= currentTime) {
            NoteRuntime nr;
            nr.track = m_noteData[m_noteIndex].track;
            nr.targetTime = m_noteData[m_noteIndex].time;
            nr.type = m_noteData[m_noteIndex].type;
            nr.y = 100.f;
            nr.noteSpeed = m_noteSpeedPixels;
            nr.active = true;
            m_noteRuntimes.push_back(nr);

            sf::CircleShape note(22.f);
            note.setFillColor(sf::Color(0, 255, 255, 220));
            note.setOutlineThickness(2.f);
            note.setOutlineColor(sf::Color(0, 200, 255));
            note.setOrigin({22.f, 22.f});
            m_activeShapes.push_back(note);
        }
        m_noteIndex++;
    }
}

float GameplayScene::getTrackCenterX(int track) const {
    float startX = (m_screenWidth - (m_trackCount * m_trackWidth
                   + (m_trackCount - 1) * m_trackSpacing)) / 2.f;
    return startX + track * (m_trackWidth + m_trackSpacing) + m_trackWidth / 2.f;
}
```

### 4.4 判定逻辑

```cpp
void GameplayScene::checkJudgment(int track) {
    float minDist = 9999.0f;
    int bestIdx = -1;
    for (int i = 0; i < (int)m_noteRuntimes.size(); ++i) {
        if (!m_noteRuntimes[i].active || m_noteRuntimes[i].processed) continue;
        if (m_noteRuntimes[i].track != track) continue;
        float dist = std::abs(m_noteRuntimes[i].y - m_judgmentLineY);
        if (dist < minDist) { minDist = dist; bestIdx = i; }
    }
    if (bestIdx < 0) return;

    JudgeResult result;
    if      (minDist < m_perfectWindow) result = JudgeResult::Perfect;
    else if (minDist < m_greatWindow)   result = JudgeResult::Great;
    else if (minDist < m_goodWindow)    result = JudgeResult::Good;
    else                                result = JudgeResult::Miss;

    onNoteJudged(result);
}

void GameplayScene::onNoteJudged(JudgeResult result) {
    switch (result) {
    case JudgeResult::Perfect:
        m_score += 100; m_combo++; m_perfectCount++;
        m_judgmentText.setString("PERFECT");
        m_lastJudgmentColor = sf::Color::Yellow;
        break;
    case JudgeResult::Great:
        m_score += 50; m_combo++; m_greatCount++;
        m_judgmentText.setString("GREAT");
        m_lastJudgmentColor = sf::Color::Cyan;
        break;
    case JudgeResult::Good:
        m_score += 25; m_combo++; m_goodCount++;
        m_judgmentText.setString("GOOD");
        m_lastJudgmentColor = sf::Color::Green;
        break;
    case JudgeResult::Miss:
        m_missCount++; m_combo = 0;
        m_judgmentText.setString("MISS");
        m_lastJudgmentColor = sf::Color::Red;
        break;
    default: return;
    }
    m_judgmentDisplayTimer = 0.8f;
    m_judgmentText.setFillColor(m_lastJudgmentColor);
    if (m_combo > m_maxCombo) m_maxCombo = m_combo;
    m_scoreText.setString("Score: " + std::to_string(m_score));
    m_comboText.setString(std::to_string(m_combo));
}
```

## 七、关键设计决策与优化方法总结

### 7.1 架构决策

| 决策 | 选择 | 理由 |
|------|------|------|
| **游玩方向** | 4K 下落式（第一位队友） | 成熟稳定，实现难度低，适合大作业 |
| **界面管理** | IScene + SceneManager（第二位队友） | 结构清晰，安全可靠，可扩展 |
| **GameplayScene** | IScene 壳 + 第一位队友芯 | 获得场景管理，保留游玩的已有实现 |
| **设置持久化** | SettingsData（第一位队友） | 实现完整，JSON 序列化直接可用 |
| **资源加载** | ResourceManager 单例 | 统一生命周期，避免重复加载 |
| **粒子渲染** | ParticleSystem VertexArray | 远优于逐 sf::CircleShape 渲染 |
| **音频同步** | MusicPlayer::getCurrentTime() | sf::Music 原生支持，直接可用 |

### 7.2 安全设计

**延迟场景切换**（来自第二位队友）：
```
场景 A::update() 调用 requestReplace(B)
 → 不立即执行，写入 m_pending
 → 等 A.update() 返回后，SceneManager 执行 applyPendingChanges()
 → 安全销毁 A，创建 B（避免"在A的成员函数中delete A"）
```

**SettingsData 自动保存**（来自第一位队友）：
```cpp
~SettingsData() { saveToFile(); }  // 析构时自动存盘
```

**帧时间上限**：
```cpp
m_deltaTime = clock.restart().asSeconds();
if (m_deltaTime > 0.05f) m_deltaTime = 0.05f;  // 防止卡顿时 dt 过大
```

### 7.3 性能优化

| 优化方法 | 使用者 | 效果 |
|----------|--------|------|
| VertexArray 批量渲染 | ParticleSystem, TitleScene | 千级粒子单次 draw call |
| 一次性构建 + 只改颜色 | TitleScene 背景 | 零渲染对象分配/帧 |
| 文字预渲染 RenderTexture | TitleScene 标题 | 48次绘制 → 3次全图 |
| Swap-and-pop 清除 | ParticleSystem | O(n) 高效移除死亡粒子 |
| ResourceManager 缓存 | 所有场景 | 每个文件只从磁盘加载一次 |
| 加法混合 BlendMode::Add | ParticleSystem | 发光效果无需额外 shader |
| std::variant 泛型存储 | SettingsData | 一组容器支持多类型 |
| 帧时间上限 dt | Application | 防止物理穿模 |

### 7.4 可扩展性预留
